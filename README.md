# 桜 Sakura — Immersive 3D Sanctuary

A breathtaking single-page immersive 3D web experience featuring a procedurally generated cherry blossom tree and a high-performance falling petal particle physics system.

## Features

- **Procedural Sakura Tree**: Recursive trunk and branch generation with bark normal mapping and thousands of instanced blossom clusters.
- **Dynamic Petal Physics**: 2,000+ instanced falling petals with wind drift, rotation turbulence, and interactive mouse repulsion.
- **Cinematic Environment**: Golden twilight lighting, volumetric atmosphere, atmospheric fog, and depth of field.
- **Minimalist UI**: Sleek dark-mode aesthetic with custom typography (`Cinzel Decorative`, `Plus Jakarta Sans`), glassmorphism controls, density toggles, and ambient wind sound generator.

## Running locally

Simply open `index.html` in any modern web browser or serve via a local static server (e.g. `npx serve`).
