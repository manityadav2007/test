# Sakura Sanctuary — Golden Hour Edition

A breathtaking single-page immersive 3D web experience featuring a procedurally generated cherry blossom tree in golden-hour light.

## Features

- **Procedural Sakura Tree**: Recursive trunk and branch generation with bark normal mapping and 10,000 instanced pink-white blossoms.
- **Golden Hour Environment**: Warm directional lighting, soft PCF shadows, custom gradient sky, and distant rolling hills.
- **Unchanged UI Overlay**: Preserved header, tabs, and interactive glassmorphism cards.
