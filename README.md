# Sakura Sanctuary — Immersive 3D Experience

A breathtaking single-page immersive 3D web experience featuring a procedurally generated cherry blossom tree and a high-performance falling petal particle physics system.

## Features

- **Procedural Sakura Tree**: Recursive trunk and branch generation with bark normal mapping and thousands of instanced blossom clusters (8,400+ flowers).
- **Realistic Petal Geometry**: Custom curved heart-shaped petals with a small notch at the tip, tumbling rotation on all 3 axes, and soft translucent materials.
- **Dynamic Petal Physics**: Instanced falling petals with wind drift, mouse repulsion, and variable density controls.
- **Golden Hour Sunset Atmosphere**: ACES Filmic tone mapping, unreal bloom post-processing, soft fog, and warm golden lighting.
- **Interactive Audio**: Ambient generative wind chimes.

## Local Development

Simply open `index.html` in any modern web browser or serve via a local static server (e.g. `npx serve`).
