# Instagram Login Page Clone

A pixel-perfect, responsive clone of the modern Instagram login web page built with HTML5, Tailwind CSS, and vanilla JavaScript.

## Features

- **Responsive Layout**: Adapts seamlessly between mobile devices and desktop screens with the iconic dual-column phone mockup preview.
- **Dynamic Phone Mockup**: Automatically rotates between Instagram screenshots on the left frame every 4 seconds.
- **Interactive Form Validation**: Dynamic button state activation requiring valid username and password inputs (minimum 6 characters).
- **Password Toggle**: Show/Hide password toggle button when typing into the password field.
- **Instagram Branding & Footer**: Authentic Meta/Instagram footer links and app store badge links.

## Getting Started

Simply open `index.html` in any web browser or serve locally using a live server.
